All-in-One Nuvio 🎬

All-in-One Nuvio is a collection of scrapers and providers for movies and TV series.

🎯 Focus

This repository is focused on movies and TV series only.

🚫 No Anime

There are no anime scrapers in this repository.

This project does not include anime providers or anime-specific sources. Its purpose is to provide scrapers for movies and TV series.

🔎 Features

Depending on the provider, scrapers can handle:

Searching for movies and TV series
Finding matching titles
Retrieving movie and series information
Finding seasons and episodes
Retrieving available sources

This project does not host, store, or upload movies or TV series.

The providers retrieve information and available sources from external websites. Users are responsible for how they use the project and for following the laws applicable in their country.
